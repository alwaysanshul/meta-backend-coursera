# Overview
Throughout this project, I strengthened my back-end development skills by designing and implementing a functional REST API for the Little Lemon restaurant using the Django REST Framework. Leveraging starter code snippets, technical documentation, and core web development concepts, I built the system from the ground up to manage table reservations.

I developed full CRUD functionality across the API endpoints, allowing the system to handle GET, POST, PUT, and DELETE HTTP requests. These requests interact seamlessly with Django models to query, create, update, and persist booking data directly into a MySQL database.
